Journal d'Epika

Epika, au cœur de l'événement, est une plateforme de découverte d'événements locaux : associations, mairies, entreprises. Ce journal raconte son développement, issue par issue : ce qui a été construit, comment, et surtout pourquoi.

Le projet

La stack

Backend

  • Symfony 7.4 LTS et API Platform, PHP 8.3
  • PostgreSQL 18 avec PostGIS (la géographie)
  • Authentification JWT dans un cookie HttpOnly
  • Tests PHPUnit

Frontend

  • Next.js 16 (React 19) et TypeScript
  • Tailwind CSS 4
  • Accessibilité RGAA 4.1.2 dès le départ
  • Tests Vitest et Playwright, audit axe

Le socle du frontend (#70) n'a pas de page à lui : rendu serveur avec Next.js, mise en page mobile d'abord dès 360 px, couche services/ pour tous les appels à l'API, composants de base (PR #115) et carte d'événement avec ses états de chargement, de vide et d'erreur (PR #154).
